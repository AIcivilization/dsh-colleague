# Skill: Coding (编码)

> 码农的核心技能 — 负责编写代码、实现功能、修复 bug

## 能力定义

```yaml
skill_id: coding
name: "编码实现"
description: "在共享工作区中编写代码、实现功能、修复 bug"
category: development
complexity: medium
```

## 核心能力

### 1. 功能实现

接收任务后，在共享工作区中编写代码：

- 遵循项目现有代码风格
- 使用项目已有的依赖和工具链
- 产出物写入共享工作区（所有同事可见）
- 完成后在黑板标记任务完成 + 附上产出物

### 2. Bug 修复

接收审核员或测试员的反馈后：

- 定位问题
- 修复代码
- 在黑板标记任务完成 + 附上修复说明

### 3. 沟通

遇到不明确的需求时：
- 通过 mailbox 问组织者
- 不要自己猜需求

## 工作流程

```
接收任务（从 mailbox）
    │
    ▼
阅读需求描述
    │
    ├── 明确 → 直接写代码
    │
    └── 不明确 → mailbox 问组织者
    │
    ▼
在共享工作区写代码
    │
    ▼
自测（基本功能能跑）
    │
    ▼
黑板更新状态 + 产出物
    │
    ▼
mailbox 通知组织者完成
```

## 产出物规范

- 文件路径用相对路径（相对于共享工作区根目录）
- 如果改了多个文件，全部列出
- summary 要简洁但包含关键信息（改了什么、为什么改）

## 禁止事项

- ❌ 不要主动写测试（那是测试员的事）
- ❌ 不要主动写文档（那是文档员的事）
- ❌ 不要做超出任务范围的重构
- ❌ 不要修改不相关文件
